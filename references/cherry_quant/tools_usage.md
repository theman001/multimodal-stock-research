> ⚠️ **이 문서는 우선순위가 낮습니다.** 아래 내용은 전략을 "구현"하는 데 필요한 핵심 로직이 아니라, 원본 자료에 포함된 부수적인 **차트/시각화 도구 사용법**입니다. 이 프로젝트(XGBoost 기반 ML 파이프라인, `CLAUDE.md` 참고)에 직접 적용되지 않으며, 필요할 때만 훑어보면 되는 참고자료입니다. 핵심 알고리즘/전략은 [`strategies.md`](./strategies.md)를 보세요.

## 1. 트레이딩뷰(TradingView) 사용법

- 용도: (1) 차트 분석, (2) 다른 전문 트레이더의 분석글 열람
- 기본 사용 흐름:
  1. 상단 검색창에서 종목 검색 (예: BTC/US, EOS, ETH) → "모든 기능을 갖춘 차트" 클릭
  2. 보조지표 추가 (이평선, MACD, RSI 등)
  3. 무료 회원은 **보조지표 3개까지만 동시 활성화 가능** — 그 이상은 유료 전환 필요
  4. 메인 → 아이디어 메뉴에서 팔로우한 트레이더의 분석글 열람 가능 (SNS 팔로우와 유사한 구조)
- 유료 전환 시 추가되는 기능: 피보나치수열, 볼린저밴드 등

## 2. 차트 시각화 라이브러리 비교 (JS 기준, 19종)

웹에서 차트를 렌더링해야 할 때 참고할 수 있는 오픈소스/상용 라이브러리 목록. 이 프로젝트는 백엔드 리서치 파이프라인이라 당장 필요하지 않지만, 추후 대시보드/리포트 시각화 단계에서 참고 가능.

| 라이브러리 | 라이선스 | 기반 | 특징 |
|---|---|---|---|
| Highcharts | 비상업 무료 / 상업 유료 | SVG | 문서화 우수, 대기업 다수 사용, 상업적 사용 시 유료 |
| Chartist.js | 오픈소스 | SVG | 애니메이션 강점, 8종 기본 차트 |
| C3.js | 오픈소스 | D3.js | 빠른 렌더링, 간단한 통합 |
| Chart.js | 오픈소스 | Canvas | 가볍고 문서화 우수, 애니메이션 기본 제공 |
| Plotly | 오픈소스(2015~) | D3.js + stack.gl | 20종 차트, 3D/통계 그래프 지원 |
| NVD3 | 오픈소스(Apache 2.0) | D3.js | JSON 직접 로드 용이 |
| FusionCharts | 유료($497~$9947) | - | 90+ 차트, 965개 지도, PNG/JPEG/SVG/PDF 내보내기 |
| DyGraphs | 오픈소스 | - | 선형회귀, 줌, 다중 그래프 동기화 |
| D3.js | 오픈소스(BSD) | - | 가장 유연하지만 학습곡선 가파름 |
| Recharts | 오픈소스(MIT) | D3.js | React 생태계에서 가장 인기, GitHub 이슈 다수 |

**결론(원문 요약)**: 대규모 데이터셋/기업용 → Highcharts, FusionCharts. 가볍고 빠른 것이 필요하면 → Chart.js, Morris.js. 그래프/네트워크 시각화 → Cytoscape, Sigma.js. 무료 오픈소스 기본 선택지 → Chart.js.
